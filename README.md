# My Developer Portfolio 🚀

Welcome to the repository for my personal portfolio website! This project was built as part of my web design coursework to showcase my background, skills, and projects as a Computer Science student.

## 🛠️ Built With
* **Semantic HTML5** - For clean, structured, and accessible markup.
* **CSS3 (Flexbox & Media Queries)** - For styling, custom layouts, and full mobile/tablet responsiveness.

## ✨ Features
* **Hero Section:** Featuring a custom layout introducing my background.
* **About & Skills:** Highlighted overview of my academic background and technical skillset (Python, C++, HTML/CSS, Godot, GDScript).
* **Featured Projects:** Showcasing games and web applications I've developed (such as *Monkey Business*).
* **Contact Links:** Quick access to my professional profiles and direct contact info.
